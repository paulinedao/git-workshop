## About <a name= "about"></a>
This repository was created for the Git workshop as part of a Code Women event.

Unlock the power of collaborative coding with our hands-on Git workshop as part of a Code Women event — in an interactive session where participants learn the essentials of version control while working together on a playful collective code project.

In this workshop, participants will:
- Discover the basics of Git and GitHub
- Learn how to branch, commit, merge, and resolve conflicts
- Experience collaborative coding in action through an incremental cadavre exquis — a collective code game where each contribution builds on the others
- Gain confidence in handling merge conflicts — one of the most common challenges in team-based development



This session is designed for all levels — whether you're new to Git or looking to refresh your skills — and offers a fun, low-stress way to experience the dynamics of collaborative software development.
